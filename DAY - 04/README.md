* Data-driven storytelling

* Data Visualization
* Data Analysis
* Business Intelligence

## Skills Demonstrated

**Power BI | Data Visualization | Data Storytelling | Dashboard Development | Data Analysis**

Developed an interactive dashboard that presents complex data in a simple and meaningful way, helping users identify trends, patterns, and key insights.
