# Excel Data Analysis Dashboard

## Overview

An **Excel-based Data Analysis project** developed to analyze sales performance and generate key business insights using formulas, functions, lookups, and summary analysis.

## Dataset

The dataset contains **500 sales records** with information including:

* Order ID
* Order Date
* Region
* City
* Segment
* Category
* Sub-Category
* Quantity
* Unit Price
* Discount
* Sales
* Profit

## Analysis Performed

* Total Sales analysis
* Total Profit analysis
* Total Quantity analysis
* Average Sales calculation
* Profit Margin calculation
* Category and regional analysis
* Sales and profit summaries
* Data organization and validation

## Excel Features Used

* `SUM`
* `AVERAGE`
* `COUNT`
* `SUMIF / SUMIFS`
* `COUNTIF / COUNTIFS`
* `IF`
* Lookup functions
* Excel Tables
* Cell references
* Data formatting

## Workbook Structure

```text
Excel Data Analysis
│
├── Raw_Data
│   └── Original sales dataset
│
├── Working
│   └── KPI calculations and analysis
│
└── Summary
    └── Final summarized results
```

## Skills Demonstrated

**Microsoft Excel | Data Analysis | Data Cleaning | Formulas & Functions | Lookup Functions | KPI Analysis | Business Reporting**

## Outcome

Created a structured Excel analysis workflow that transforms raw sales data into meaningful KPIs and summarized business insights.
