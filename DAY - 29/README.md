# Day 29 – Basic Conditional Formatting in Excel

## 📌 Project Overview
This project focuses on applying **Basic Conditional Formatting in Microsoft Excel** to a Superstore dataset. Conditional formatting helps highlight important values, identify high and low sales, detect negative profits, and improve data readability through visual formatting rules.

## 🎯 Objectives
- Identify the top 10 and bottom 10 sales values.
- Highlight the highest profit values.
- Identify loss-making transactions using negative profit values.
- Visualize quantity values using data bars.
- Compare discount values using color scales.
- Improve data interpretation through Excel formatting techniques.

## 🛠️ Tools Used
- Microsoft Excel
- Conditional Formatting
- Superstore Dataset

## 📂 Dataset Description
The dataset contains Superstore transaction information, including the following attributes:

- Order ID
- Order Date
- Region
- City
- Segment
- Category
- Sub-Category
- Product Name
- Quantity
- Discount
- Sales
- Profit

## 📊 Tasks Performed

### 1. Top 10 Sales
Highlighted the 10 highest sales values using green formatting to identify high-value transactions.

### 2. Bottom 10 Sales
Highlighted the 10 lowest sales values using red formatting to identify low-value transactions.

### 3. Top 10 Profit
Applied conditional formatting to highlight the highest profit values.

### 4. Negative Profit Analysis
Highlighted negative profit values in red to identify transactions resulting in losses.

### 5. Quantity Analysis
Applied data bars to compare quantities visually.

### 6. Discount Analysis
Applied color scales to distinguish low, medium, and high discount values.

## 🔍 Key Learnings
- Understanding Excel conditional formatting rules.
- Applying top and bottom value highlighting.
- Identifying negative values using cell rules.
- Using data bars and color scales for visual analysis.
- Improving spreadsheet readability and analytical presentation.

## 📁 Project Files
- `Superstore_Dataset.xlsx` – Original dataset.
- `Conditional_Formatting.xlsx` – Workbook containing conditional formatting work.

## ✅ Conclusion
This task provided practical experience with Excel's conditional formatting features and demonstrated how visual rules can help identify important sales and profit patterns efficiently.
