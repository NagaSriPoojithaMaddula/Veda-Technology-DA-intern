# Day 7 – First Chart Story: Turning Numbers into a Narrative

## 📌 Project Overview
This project focuses on transforming the Iris dataset into a clear and
meaningful visual story using Microsoft Excel.

The objective was to summarize the dataset, create appropriate
visualizations, identify patterns across Iris species, and communicate
the findings through concise data-driven insights.

---
## 🎯 Objectives

- Analyze the Iris dataset using Excel.
- Calculate average measurements for each Iris species.
- Compare species based on sepal and petal characteristics.
- Create simple and meaningful visualizations.
- Add clear takeaways to each chart.
- Combine the visualizations into a single dashboard and narrative.

---

## 📊 Dataset

The dataset contains 80 observations of Iris flowers with the following
attributes:

| Feature | Description |
|---|---|
| Sepal_Length_cm | Length of the sepal in centimeters |
| Sepal_Width_cm | Width of the sepal in centimeters |
| Petal_Length_cm | Length of the petal in centimeters |
| Petal_Width_cm | Width of the petal in centimeters |
| Species | Iris flower species |

### Species Included

- Setosa
- Versicolor
- Virginica

---

## 🛠️ Tool Used

**Microsoft Excel**

The analysis was performed using Excel formulas, summary tables,
charts, and a dashboard.

---

## 📁 Workbook Structure

The Excel workbook contains three sheets:

### 1. Iris_Data
Contains the original 80-row Iris dataset used for the analysis.

### 2. Summary
Contains calculated average measurements for each Iris species.

The following metrics were summarized:

- Average Sepal Length
- Average Sepal Width
- Average Petal Length
- Average Petal Width

### 3. Dashboard
Contains the final visual story with four charts and key insights.

---

## 📈 Visualizations Created

### 1. Average Petal Length by Species
**Chart Type:** Bar Chart

This visualization compares the average petal length among the three
Iris species.

**Insight:** Virginica has the highest average petal length, while
Setosa has the lowest.

---

### 2. Average Sepal Length Across Species
**Chart Type:** Line Chart

This visualization shows how the average sepal length varies among
the three species.

**Insight:** Average sepal length is higher for Virginica than for
Setosa and Versicolor.

---

### 3. Iris Species Distribution
**Chart Type:** Pie Chart

This visualization represents the distribution of observations across
the three Iris species.

**Insight:** The dataset is nearly evenly distributed among Setosa,
Versicolor, and Virginica.

---

### 4. Average Petal Width by Species
**Chart Type:** Bar Chart

This visualization compares the average petal width across the three
species.

**Insight:** Virginica has the highest average petal width, while
Setosa has the lowest.

---

## 🔎 Key Findings

The analysis highlights clear differences among the three Iris species,
particularly in petal-related measurements.

- Virginica has the highest average petal length and petal width.
- Setosa has the lowest average petal length and petal width.
- Sepal measurements also vary across the three species.
- The dataset contains a nearly balanced number of observations for
  each species.

These patterns become easier to identify through visual comparison.

---

## 📖 Overall Data Story

The visualizations demonstrate that petal measurements provide a clear
way to distinguish the three Iris species. Setosa generally has the
smallest petal dimensions, while Virginica has the largest. Sepal
measurements also show variation between species, while the species
distribution remains nearly balanced. Together, the charts transform
the numerical dataset into an easy-to-understand visual narrative.
