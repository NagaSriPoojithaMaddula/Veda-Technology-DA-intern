# Day 25 – Basic Data Validation in Excel

## 📌 Project Overview
This task focuses on implementing **data validation in Microsoft Excel** to improve data accuracy, maintain consistency, and prevent invalid entries in an employee dataset containing 500 records.

## 🎯 Objectives
- Create dropdown lists for predefined employee attributes.
- Restrict invalid age, salary, and joining date entries.
- Improve data quality and consistency.
- Apply validation rules to an employee dataset using Excel.

## 📂 Dataset Description
The dataset contains 500 employee records with the following columns:

- Employee ID
- Employee Name
- Department
- Gender
- Employment Type
- Age
- Joining Date
- Monthly Salary (INR)
- Email
- Employment Status

## 🛠️ Tools Used
- Microsoft Excel
- Excel Data Validation
- Dropdown Lists
- Data Quality Checks

## ⚙️ Tasks Performed

### 1. Dropdown List Validation
Created dropdown lists for:
- **Department:** HR, IT, Finance, Sales, Marketing, Operations, Customer Support
- **Gender:** Female, Male, Other
- **Employment Type:** Full-Time, Part-Time, Contract, Intern
- **Employment Status:** Active, On Leave, Inactive

### 2. Age Validation
Restricted age entries to whole numbers between **18 and 60**.

### 3. Salary Validation
Restricted monthly salary entries to whole numbers between **₹10,000 and ₹2,00,000**.

### 4. Joining Date Validation
Allowed joining dates between **1 January 2000 and 31 December 2026**.

### 5. Error Alerts
Configured validation rules to reject invalid entries and guide users toward acceptable values.

## 📊 Key Outcomes
- Improved consistency across employee records.
- Reduced the risk of incorrect data entry.
- Standardized department and employment-related values.
- Established validation rules for more reliable data management.

## 📁 Files Included
- `Employee_Dataset.xlsx` – Original employee dataset.
- `Data Validation.xlsx` – Workbook containing the raw data and the validated worksheet.

## 📚 Learning Outcomes
- Learned how to create dropdown lists in Excel.
- Practiced number and date validation.
- Understood how validation rules help maintain data quality.
- Improved practical Excel skills for data analytics.

## ✅ Conclusion
This task demonstrated how Excel Data Validation can help maintain accurate, consistent, and reliable employee data. These techniques are useful in data cleaning, reporting, and everyday data analytics workflows.
