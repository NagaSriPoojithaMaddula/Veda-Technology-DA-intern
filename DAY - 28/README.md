# Day 28 – Simple Percentage Analysis using Excel

## 📌 Project Overview
This project focuses on analyzing category-wise sales contribution using Microsoft Excel. The objective is to calculate the percentage contribution of each product category to total sales and represent the results using a chart.

## 🎯 Objectives
- Calculate total sales for each product category.
- Determine the percentage contribution of each category.
- Verify that the total percentage contribution equals 100%.
- Create a chart to visualize category-wise sales performance.
- Understand how percentage analysis supports business reporting and decision-making.

## 🛠️ Tools Used
- Microsoft Excel
- Excel Formulas
- Pie Chart / Doughnut Chart

## 📂 Dataset Description
The Superstore dataset contains sales transaction details, including:
- Order ID
- Order Date
- Region
- City
- Segment
- Category
- Sub-Category
- Product Name
- Quantity
- Discount
- Sales
- Profit

## 📊 Analysis Performed
1. Calculated category-wise sales using the `SUMIF` function.
2. Calculated grand total sales using the `SUM` function.
3. Computed contribution percentages using the formula:

   **Contribution % = (Category Sales / Grand Total Sales) × 100**

4. Verified the total percentage contribution.
5. Created a category-wise sales contribution chart.
6. Formatted the analysis table for clear and professional presentation.

## 📈 Key Findings
- **Technology:** Contributes 65.72% of total sales and is the highest-performing category.
- **Furniture:** Contributes 29.06% of total sales.
- **Office Supplies:** Contributes 5.22% of total sales and has the lowest contribution.
- **Grand Total Sales:** ₹1,58,802.19.
- **Total Contribution:** 100%.

## 💡 Business Insights
- Technology generates the largest share of sales among the three categories.
- Furniture is the second-largest contributor to overall sales.
- Office Supplies has a comparatively smaller share of total sales.
- Percentage contribution analysis helps businesses compare categories and identify major sales drivers.

## 📁 Deliverables
- Excel workbook containing the dataset and percentage analysis.
- Category-wise sales contribution table.
- Pie chart or doughnut chart showing percentage contributions.

## 🏁 Conclusion
This task provided practical experience in calculating percentage contributions, using Excel formulas, validating totals, and visualizing business data. The analysis demonstrates how Excel can be used to communicate sales performance clearly and support data-driven decision-making.
