📌 Project Overview

This project focuses on practicing Microsoft Excel fundamentals for data analysis using a sales transaction dataset.

The objective was to understand how Excel can be used to organize data, perform calculations, analyze sales information, classify transactions, manipulate text, and retrieve related information.

🎯 Objectives
Understand the structure of a sales dataset.
Perform sales and discount calculations.
Apply conditional logic.
Work with text-based data.
Analyze data based on specific conditions.
Practice lookup and data-retrieval techniques.
Develop practical Excel data analysis skills.
Improve data organization and formatting.
📊 Dataset

The project uses a Sales Transaction Dataset containing customer, product, pricing, discount, quantity, and payment information.

Dataset Columns
Column	Description
Transaction_ID	Unique identifier for each transaction
Date	Date of the transaction
Customer_ID	Unique customer identifier
Customer_Name	Customer name
Product_ID	Unique product identifier
Product_Name	Name of the product
Category	Product category
Quantity	Number of units purchased
Unit_Price	Price per unit
Discount	Discount applied to the transaction
Payment_Mode	Method used for payment

Lookup Functions

Practiced:

VLOOKUP – Retrieve related information from a table.
XLOOKUP – Perform flexible lookup and data retrieval.
INDEX – Retrieve information based on a position.
MATCH – Identify the position of a specific value.
INDEX + MATCH – Combine lookup and position-based retrieval techniques.
