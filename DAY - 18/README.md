# 📊 Region Performance Analysis

## 📌 Project Overview

This project focuses on analyzing regional sales and profit performance using a retail sales dataset. The analysis was performed using **Microsoft Excel** and **Power BI** to compare regions, evaluate profitability, calculate profit margins, and rank regions based on sales and profit.

## 🎯 Objectives

- Analyze sales performance across different regions.
- Compare total sales and total profit.
- Calculate profit margin for each region.
- Rank regions based on sales performance.
- Rank regions based on profit performance.
- Identify the highest and lowest performing regions.
- Create meaningful visualizations for business insights.

## 📂 Dataset

The analysis was performed using a retail **Superstore dataset** containing information such as:

- Order ID
- Order Date
- Category
- Sub-Category
- Region
- Segment
- City
- Quantity
- Discount
- Sales
- Profit

## 📊 Key Analysis

### 1. Sales Performance by Region

Regional sales were calculated and compared to identify the highest and lowest sales-performing regions.

### 2. Profit Performance by Region

Total profit was calculated for each region to evaluate regional profitability.

### 3. Profit Margin

Profit Margin was calculated using:

`Profit Margin = Total Profit / Total Sales`

### 4. Regional Ranking

Regions were ranked separately based on:

- Sales
- Profit

## 🔍 Key Insights

- 🥇 **South** recorded the highest sales with **₹99,647.70**.
- 💰 **Central** generated the highest profit with **₹13,105.11**.
- 📈 **Central** achieved the highest profit margin of **13.59%**.
- 📉 **West** recorded the lowest sales and profit.
- 🔄 The region with the highest sales was not the region with the highest profit.
- 📊 **East and South** have the same displayed profit margin of **12.76%** when rounded to two decimal places.
