# 🛒 E-Commerce Customer Segmentation Using RFM Analysis

## 📌 Project Overview

This project focuses on analyzing e-commerce customer purchasing behaviour using **RFM (Recency, Frequency, Monetary) Analysis**.

The objective is to identify different customer groups based on their purchasing patterns and understand their contribution to business revenue.

Using Python for data cleaning, preprocessing, and customer segmentation, the project applies RFM scoring to classify customers into meaningful segments. An interactive dashboard is developed using Microsoft Power BI to present customer insights and support data-driven business decisions.

---

## 🎯 Project Objectives

- Analyze e-commerce transaction data.
- Perform data cleaning and preprocessing.
- Calculate Recency, Frequency, and Monetary values.
- Assign RFM scores to customers.
- Segment customers based on purchasing behaviour.
- Identify valuable, loyal, new, at-risk, and lost customers.
- Analyze customer distribution and revenue contribution.
- Develop an interactive Power BI dashboard.
- Provide actionable business recommendations.

## ⚙️ Project Methodology

### 1. Data Loading and Exploration
- Loaded the Online Retail II dataset using Pandas.
- Examined dataset dimensions and column names.
- Checked data types and missing values.
- Identified duplicate records.

### 2. Data Cleaning and Preprocessing
- Removed records with missing Customer IDs.
- Removed duplicate transactions.
- Converted InvoiceDate into datetime format.
- Excluded cancelled transactions.
- Removed records with invalid or negative Quantity and Price values.
- Created a Revenue column.

**Revenue Calculation:**

Revenue = Quantity × Price

### 3. Business Overview

Analyzed important business metrics:

- Total Transactions
- Total Customers
- Total Products
- Total Countries
- Total Revenue
- Average Order Value

### 4. RFM Analysis

Calculated three important customer metrics:

| Metric | Description |
|---|---|
| Recency | Number of days since the customer's last purchase |
| Frequency | Number of unique invoices generated by the customer |
| Monetary | Total revenue generated by the customer |

### 5. RFM Scoring

Assigned scores ranging from 1 to 5 using quintile-based scoring.

- **Recency Score:** Customers with more recent purchases receive higher scores.
- **Frequency Score:** Customers with more purchases receive higher scores.
- **Monetary Score:** Customers generating higher revenue receive higher scores.

The individual scores were combined to calculate the RFM Score and Total RFM Score.

### 6. Customer Segmentation

Applied rule-based segmentation using Recency and Frequency scores.

Customers were classified into six categories:

| Customer Segment | Description |
|---|---|
| Champions | Recent and frequent customers |
| Loyal Customers | Customers with consistent purchasing behaviour |
| Potential Loyalists | Customers with potential to become loyal |
| New Customers | Recently acquired customers |
| At-Risk Customers | Previously active customers with reduced recent activity |
| Lost Customers | Customers with low recency and frequency scores |

### 7. Final Customer Segmentation Dataset

The final customer-level dataset contains:

- Customer ID
- Recency
- Frequency
- Monetary
- R_Score
- F_Score
- M_Score
- RFM_Score
- RFM_Total
- Customer_Segment
