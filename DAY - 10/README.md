# 📊 Simple KPI Tracking Sheet – Excel

## 📌 Project Overview

This project focuses on creating a **Simple KPI Tracking Sheet using Microsoft Excel** to monitor important sales performance indicators from a sample Superstore sales dataset.

The dashboard summarizes key business metrics such as **Total Revenue, Units Sold, Number of Orders, Average Order Value, and Top Product**.

The KPI calculations are performed using Excel formulas so that the results can be updated when new sales records are added to the dataset.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze sales transaction data using Microsoft Excel.
- Calculate important business KPIs.
- Create a simple and professional KPI summary sheet.
- Identify the top-performing product based on sales.
- Use Excel formulas for automated calculations.
- Create a structure that can be updated when new data is added.

---

## 📂 Dataset

The dataset contains sales transaction information with the following columns:

| Column | Description |
|---|---|
| Order ID | Unique identification number for each order |
| Order Date | Date on which the order was placed |
| Product ID | Unique identification code of the product |
| Category | Product category |
| Product Name | Name of the product |
| Quantity | Number of units sold |
| Sales | Revenue generated from the order |

### Dataset Details

- **Total Records:** 50
- **Categories:** Technology, Office Supplies, Furniture
- **Number of Products:** 15
- **Data Type:** Sales transaction data

2. Units Sold

3. Number of Orders

Total number of sales orders in the dataset.

Excel Formula:

=COUNTA(Sales_Data[Order ID])

Result:

50 orders

4. Average Order Value

Average revenue generated per order.

Excel Formula:

=C5/C7

Result:

$454.50

Calculation:
Average Order Value
= Total Revenue / Number of Orders
= 22,725 / 50
= $454.50
