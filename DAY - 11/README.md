# 📊 Day 11 — Data Sorting & Filtering | Excel
**Data Analytics Internship — Veda Technology**

## 📌 Project Overview

This project is part of my **Data Analytics Internship at Veda Technology**, where I worked with a structured sales dataset to practice fundamental **data analysis techniques using Microsoft Excel**.

The primary focus of this task was to understand how raw business data can be organized, sorted, filtered, and analyzed to answer practical business questions.

The task also involved applying **multiple filtering conditions** and presenting the results in a clear and professional format.

---

## 🎯 Objectives

The key objectives of this task were to:

- Analyze a structured sales dataset
- Perform data sorting and filtering in Excel
- Apply categorical and numerical filters
- Use multiple conditions to identify specific records
- Analyze sales and profit information
- Answer business-oriented questions using Excel
- Preserve the original raw dataset
- Present the results in a structured and understandable manner

## 🗂️ Dataset

The dataset represents **store/sales transaction data** containing information about orders, products, locations, sales, quantities, and profits.

### Dataset Attributes

| Column | Description |
|---|---|
| Order ID | Unique identifier for each order |
| Order Date | Date of the order |
| Region | Geographic sales region |
| State | State associated with the order |
| Category | Main product category |
| Sub-Category | Product sub-category |
| Product | Name of the product |
| Unit Price | Price per individual unit |
| Quantity | Number of units ordered |
| Sales | Total sales generated |
| Profit | Profit generated from the order |

## 🔍 Analysis Performed

### 1️⃣ Sales Sorting

Sorted the **Sales** column to identify orders with higher and lower sales values.

**Technique:**  
`Sort Largest to Smallest`

---

### 2️⃣ Regional Filtering

Filtered the dataset based on:
```text
Region = West
This helped identify all orders belonging to the West region.

3️⃣ Technology Sales Analysis

Applied multiple conditions to identify Technology orders based on sales value.

Category = Technology
AND
Sales > 500

This demonstrated the use of multiple filters in Excel.

4️⃣ Negative Profit Analysis

Filtered orders where:

Profit < 0

This helped identify transactions that generated negative profit and could require further business investigation.

5️⃣ State & Category Filtering

Applied multiple categorical conditions to identify records based on:

State = Texas
AND
Category = Office Supplies
6️⃣ Quantity & Sales Analysis

Applied multiple numerical conditions:

Quantity > 5
AND
Sales > 300

This helped identify orders involving higher quantities and higher sales values.

📊 Key Business Questions

The analysis was designed around practical business questions such as:

Which orders belong to a specific region?
Which Technology orders generated higher sales?
Which orders generated negative profit?
Which orders belong to a particular state and category?
Which orders have both high quantity and high sales?

These questions demonstrate how Excel filtering can be used to extract relevant information from a larger dataset.
