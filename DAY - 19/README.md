# 📊 Day 19 – Top 10 Products by Sales

## 📌 Project Overview

This task focuses on identifying the **Top 10 Products based on total sales** using Microsoft Excel.

The analysis was performed using a Superstore sales dataset containing 1,000 records and 15 columns. The data was analyzed at the product level to determine which products generated the highest total sales.

## 🎯 Objective

- Identify the Top 10 products based on total sales.
- Practice sorting and ranking techniques in Excel.
- Aggregate sales for each product.
- Create a clear Top 10 sales table.
- Visualize the results using a bar chart.
- Check the ranking for possible ties.

## 🗂️ Dataset

**Dataset:** Superstore Sales Dataset

The dataset contains information related to:

- Order ID

- Ship Date
- Customer Name
- Segment
- Region
- State
- City

For this analysis, the primary columns used were:

- **Product**
- **Sales**

## 🛠️ Tool Used

- Microsoft Excel

## 🔍 Methodology

### 1. Data Preparation
The Superstore dataset was imported into Microsoft Excel and reviewed to understand the available columns and data.

### 2. Sales Aggregation
A PivotTable was created to calculate the **total sales for each product**.

### 3. Sorting
Products were sorted in **descending order of total sales**, placing the highest-selling products first.

### 4. Top 10 Selection
The first 10 products after sorting were selected as the Top 10 products.

### 5. Ranking
Each product was assigned a rank from 1 to 10 based on total sales.

### 6. Visualization
A horizontal bar chart was created to compare the sales performance of the Top 10 products.
